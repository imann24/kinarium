# Landing typography

Self-hosted Latin WOFF2 files, both under the SIL Open Font License 1.1.

- `DelaGothicOne-Latin.woff2`: Dela Gothic One Regular, Fontsource 5.2.5, https://cdn.jsdelivr.net/npm/@fontsource/dela-gothic-one@5.2.5/files/dela-gothic-one-latin-400-normal.woff2
- `Manrope-Latin.woff2`: Manrope variable weight, Fontsource 5.2.8, https://cdn.jsdelivr.net/npm/@fontsource-variable/manrope@5.2.8/files/manrope-latin-wght-normal.woff2

The adjacent OFL files come from each family's directory in https://github.com/google/fonts/tree/main/ofl. The Latin subsets total approximately 37 KB. Other scripts fall back to the browser's sans-serif font.
